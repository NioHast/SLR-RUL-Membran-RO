# docs/ - SLR Deliverables

Contains the main outputs (final results), not raw data:
- `SLR_Protocol.txt` - SLR protocol (RQ, PICOC, search string, inclusion/exclusion criteria, quality assessment).
- `SLR_Korpus.xlsx` - the 101-article corpus for the SLR.
- `SLR_Korpus.xlsx`: sheet "SLR - Korpus Jurnal" (columns: No, Pilar, Judul, Penulis, Tahun, Jurnal, Klasifikasi,
  **Relevansi**, **Kualitas**, DOI, Ringkasan, Kontribusi), "Matriks Konsep (Webster-Watson)",
  "Sintesis & Gap Final", "Peta Teori ke Dimensi", "Konsep Kunci Model", "Ringkasan & Status".
- `SLR_Laporan.docx` / `.pdf` - full SLR report (Times New Roman, margins 4-4-3-3, 1.5 line spacing).
- `SLR_Artikel_Jurnal.docx` / `.pdf` - journal article version (2 columns).
- `SLR_Presentasi.html` + `SLR_Presentasi.pdf` - slides (reveal.js, dark theme; 16:9 PDF for full screen).
- `SLR_Draft.txt` - text version of the report.
- `Catatan_Keputusan.txt` - decision & assumption log.
- `SUBSTITUTION_LOG.txt` - log of replacement/exclusion of other papers (beyond the 3 mismatches).
- `FULLTEXT_SCREENING_LOG.txt` - full-text screening log + PRISMA.
- `PLAN_PHASE5.txt` - plan for in-depth per-paper analysis (Phase 5).
- `KAGGLE_PHASES_REPORT.txt` - Kaggle pipeline report.
