PAPER 101: Modeling dependent degradation data considering inherent causal relationships for reliability analysis and remaining useful life prediction
Penulis: Shi-Shun Chen, Xiao-Yang Li (Beihang University) | Tahun 2026 | Reliability Engineering & System Safety | Q1 | DOI 10.1016/j.ress.2026.113080
Status inklusi: diterima | Relevansi: Pendukung

1. KARAKTERISTIK STUDI
Studi metodologis di bidang prognostik dan health management (PHM). Masalah: pemodelan degradasi dependen pada sistem multi-indikator. Kritik utama terhadap literatur: model dependen berbasis korelasi (kovarians/kopula) bersifat simetris dan mengabaikan arah kausalitas fisik antar jalur degradasi, sehingga menimbulkan inferensi fisis yang salah (contoh: FF -> EGT pada mesin terbang). Tujuan: membangun kerangka "causality-driven" yang menggabungkan proses stokastik, causal discovery, dan neural network dalam kerangka Bayes untuk analisis reliabilitas dan prediksi RUL.

2. METODE
- Model degradasi univariat per indikator: proses Wiener dengan tren deterministik (Y(t)=Y0+a*Psi(t;beta)) + multi-sumber ketidakpastian (Y0 acak, laju degradasi a acak, Wiener sigma*B(t), measurement error epsilon). Estimasi parameter via maximum likelihood dengan optimizer metaheuristik TERIME (improved RIME).
- Causal discovery: algoritma Stable-PC (partial correlation + Fisher z; skeleton -> orientasi V-structure -> Meek rules -> orientasi via pengetahuan domain) pada increment degradasi (bukan nilai mentah) untuk mencegah dependensi semu akibat tren non-stasioner.
- Pemodelan efek kausal: uncertainty-aware neural network memetakan parent state -> child state dan mengeluarkan mean serta varians (NLL loss).
- Fusion Bayes: prior dari model univariat (populasi) digabung dengan informasi kausalitas (unit-spesifik) untuk membentuk posterior prediktif.
- Reliabilitas & RUL: margin performa M(t) dengan logika seri; R(t)=Pr{M(t)>0} dan T_RUL=inf{t>tn|M(t)<=0}, diselesaikan via Monte Carlo.

3. DATA
NASA C-MAPSS subset FD001 (turbofan, run-to-failure). 100 mesin; 88 untuk pengembangan (70 latih, 18 validasi), 12 uji. 14 sensor; dua indikator dipilih: U8 (rasio aliran bahan bakar terhadap tekanan statis outlet HPC) dan U14 (coolant bleed LPT). Ambang kegagalan U8=519,6 dan U14=23,07. Denoising via moving average (window 15). Data uji dihentikan sebelum gagal, namun tidak diperlakukan sebagai observasi tersensor.

4. TEMUAN UTAMA
- Prediksi degradasi U14: RMSE turun 30,2%, MAE 23,4%, CRPS 27,6% vs model korelasi terbaik (M2). Tabel 5: usulan 0,074/0,059/0,042 vs M2 0,106/0,077/0,058.
- RUL: usulan RMSE 40,16 / MAE 25,19 / CRPS 19,04, mengurangi ~22%/29%/35% vs korelasi terbaik; saat U14 tidak terukur tetap 40,17/25,21/19,05 (variasi <0,1%), sedangkan model lain memburuk 60-80%.
- Ablation: menghilangkan model univariat (M5) menaikkan CRPS 14% (0,048 vs 0,042); model independen (M4) jauh lebih buruk (RMSE 0,619).
- Reliabilitas: model usulan memperlambat penurunan R<0,9 ke siklus 159 (vs M2=156, M3=153, independen=152, M1=151), menghilangkan skenario tak-fisis (U8 lambat namun U14 cepat).
- Sensitivitas: robust terhadap learning rate (0,001-0,01) dan jumlah neuron (4-16); arah kausal U8->U14 lebih baik dari U14->U8, namun keduanya tetap mengalahkan model korelasi.

5. RELEVANSI KE TESIS
Tesis: RUL membran RO/desalinasi via survival analysis + deep learning dengan data tersensor. Paper ini bukan domain membran dan tidak menangani data tersensor, sehingga tidak langsung menjadi Inti. Namun relevan sebagai reference metodologis (Pendukung): (a) menunjukkan pola pemodelan dependensi multi-indikator antar jalur degradasi yang dapat dipetakan ke keterkaitan parameter fouling membran (mis. tekanan trans-membran vs fluks vs konduktivitas); (b) memperlihatkan cara menggabungkan prior proses stokastik (Wiener) dengan model pembelajaran (neural network) dalam framework Bayes — analog dengan menghubungkan survival model baseline dengan deep learning; (c) metrik probabilistik (CRPS, NLL, interval kredibel) sejalan dengan kebutuhan pelaporan ketidakpastian RUL. Kontribusi konseptual yang dapat dikutip: kausalitas eksplisit mengalahkan korelasi simetris dalam model degradasi dependen.
