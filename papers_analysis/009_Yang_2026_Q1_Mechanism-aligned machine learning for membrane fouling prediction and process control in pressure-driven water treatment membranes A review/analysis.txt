PAPER 016 - Yang et al. (2026)
Judul   : Mechanism-aligned machine learning for membrane fouling prediction and process control in pressure-driven water treatment membranes: A review
Jurnal  : Journal of Water Process Engineering | Scopus Q1 (SCImago SJR Best Quartile) | DOI 10.1016/j.jwpe.2026.110543
Pilar   : E. Membrane/RO/Desalination
Relevansi: Konteks  (tinjauan domain membran/RO + kontrol DSS; tanpa RUL/survival/censoring)

KARAKTERISTIK STUDI
Tinjauan kritis yang membangun kerangka machine learning selaras-mekanisme untuk prediksi fouling dan kontrol proses membran UF/NF/RO. Empat pertanyaan pemandu: mekanisme fouling dominan? struktur data tersedia? arsitektur model cocok? keputusan operasional apa yang didukung?

METODE
- Pencarian transparan: 6 database (Scopus, WoS, ScienceDirect, Google Scholar, IEEE Xplore, PubMed) + citation tracking; 1822 record ->274 artikel final.
- Kerangka mechanism-to-control: mekanisme -> signature data -> model -> output -> aksi kontrol terjaga.
- Model: GRU (UF), XGBoost terregularisasi (NF), CNN-GRU-SHAP (RO); XAI, digital twin, PINN dibahas.
- Benchmarking: validasi kronologis/rolling/cross-site, uncertainty metrics, fallback control.

DATA
Review, tanpa data primer. Table 1 memberi rentang kuantitatif (separasi UF/NF/RO, tekanan/TMP, flux/rejection, interval sampling, ambang peringatan, waktu latih, latency). Membahas SCADA noise, missing data (MCAR/MNAR), kalman/EWMA filtering.

TEMUAN UTAMA
- Pemetaan proses-model: UF-GRU (TMP/flux frekuensi tinggi), NF-XGBoost (DOM/kation multikolinear), RO-CNN-GRU-SHAP (biofouling/scaling heterogen + OCT/hyperspectral).
- Target prediksi = endpoint plant: kenaikan TMP, kehilangan permeabilitas, probabilitas melewati ambang cleaning, expected time to CIP, warning score modul.
- Aksi kontrol: backwash scheduling, koagulan/pH/antiscalant dosing, targeted cleaning/CIP, biocide zoning - semua dengan safeguards.
- Validasi ketat: random split menyesatkan untuk data terautokorelasi; gunakan chronological/rolling/cross-season/cross-site + uncertainty interval.
- Data sparsity: fallback ke XGBoost/rule-based; federated learning untuk transfer lintas plant (future work).

RELEVANSI KE TESIS
Sangat relevan sebagai konteks domain: menunjukkan bagaimana sinyal membran RO (ΔP, salt passage, pH, recovery) dipetakan ke aksi kontrol/pemeliharaan, dan menyebut endpoint mirip RUL (expected time to CIP). Namun tidak memakai survival analysis/censoring maupun memprediksi RUL langsung. Tier = Konteks (DSS/IS + domain membran).
