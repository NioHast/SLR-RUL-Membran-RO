PAPER 012 - Gao et al. (2025)
Judul   : A Neural Network-Based Survival Analysis Model Considering Censored Data for Failure Prediction
Jurnal  : IEEE Transactions on Automation Science and Engineering | Scopus Q1 (SCImago SJR Best Quartile) | DOI 10.1109/TASE.2025.3640217
Pilar   : A. Survival Analysis & Censored Data
Relevansi: Inti-Metode  (RUL + survival/censoring/Weibull; domain non-membran)

KARAKTERISTIK STUDI
Mengusulkan Bayesian LSTM-SURV yang menggabungkan survival analysis dengan neural network untuk memodelkan hubungan non-linear antara sinyal degradasi multi-sensor dan RUL dengan adanya data tersensor. Alih-alih memprediksi RUL langsung, model memprediksi distribusi masa pakai (Weibull), sehingga ketidakpastian dapat dikuantifikasi. Motivasi: di lapangan, proporsi besar data tersensor (mis. 90,2% heart failure, 98,8% hard disk, >95% railway/aviation).

METODE
- Bayesian LSTM-SURV: LSTM -> dropout -> FC1 -> FC2 -> output parameter Weibull (lambda scale, k shape) via Softplus.
- Loss = likelihood survival analysis: untuk data lengkap f(t_i), untuk tersensor S(t_i); ditambah penalti k>1.
- Pemodelan mixed-effects Bayesian untuk denoising sinyal + Bayesian updating pada tahap online (transfer informasi prior ke unit uji).
- Hyperparameter via Bayesian optimization + 5-fold CV; benchmark DeepSurv dan TSNN.

DATA
Simulasi: 2 sensor, regresi polinomial (1,t,t^2) + random effects; 500 unit latih, 100 unit uji; variasi p1 (persen data lengkap=0,3/0,5/0,7) dan p2 (persen waktu pencensoringan=0,2/0,4/0,6/0,8). Kasus nyata: C-MAPSS FD001 (100 unit latih/20.631 siklus; 100 unit uji/13.096 siklus).

TEMUAN UTAMA
- Loss likelihood SA memungkinkan NN memakai data tersensor tanpa label RUL; menghindari bias akibat mengabaikan data tersensor.
- RMSE terbaik 4,420 (p1=0,7, p2=0,8) mengalahkan TSNN (6,757) dan DeepSurv (25,299). DeepSurv terburuk karena hanya pakai observasi terakhir.
- Output distribusi (PDF, survival function, 90% CI): semua true lifetime contoh jatuh dalam 90% CI; P_CI meningkat saat unit mendekati kegagalan.
- Bayesian updating menurunkan noise dan memperbaiki prediksi unit berdata sedikit (awal prediksi condong ke tren populasi).

RELEVANSI KE TESIS
Sangat relevan sebagai kerangka metode: kombinasi tepat survival analysis + deep learning + data tersensor + ketidakpastian, yang menjadi inti proposal tesis. Kekurangannya domain non-membran (turbin gas) dan tidak menganalisis keputusan pemeliharaan spesifik. Tier: Inti-Metode.
