PAPER 020 - Dhada et al. (2022)
Judul   : Weibull recurrent neural networks for failure prognosis using histogram data
Jurnal  : Neural Computing and Applications | Scopus Q1 (ScImago SJR Best Quartile) | DOI 10.1007/s00521-022-07667-7
Pilar   : A. Survival Analysis & Censored Data
Relevansi: Inti-Metode  (RUL/failure + survival/Weibull/censoring; domain armada truk)

KARAKTERISTIK STUDI
Use case industri pertama WTTE-RNN (Weibull time-to-event recurrent neural network) untuk prognosis kegagalan turbocharger armada truk Scania. Data kondisi berbentuk histogram jarang ter-sampling. WTTE-RNN mengoptimalkan parameter distribusi Weibull waktu-ke-kegagalan via RNN dengan loss log-likelihood yang memanfaatkan data tersensor.

METODE
- WTTE-RNN: RNN mengoptimalkan log-likelihood Weibull diskret, L = u_t*log(e^d(t)-1) - Lambda(t+1), dengan indikator censoring u_t.
- Preprocessing histogram: differencing snapshots + normalisasi; reduksi dimensi via relative entropy (overlap antar histogram berurutan + terhadap histogram sehat) -> ~1/30 fitur.
- Mode distribusi densitas Weibull = prediksi waktu kegagalan; distribusi dievaluasi ulang tiap snapshot baru.
- Eksperimen: (1) uncensored saja (cluster-specific vs general), (2) campuran censored+uncensored; uji rasio censoring 4:1, 1:1, 1:15.

DATA
Armada truk heavy-duty Scania (turbocharger). 14 fitur histogram (ambient temp/pressure, axle load, boost pressure) + 6 kategorikal + 3 skalar; 10-30 snapshot/truk; 14% truk gagal.

TEMUAN UTAMA
- Menambahkan data tersensor memperbaiki prediksi (varians galat menjelang kegagalan hampir separuh).
- Rasio tersensor:tak-tersensor 15:1 merusak performa (over-generalization loss Weibull); ada proporsi optimal.
- Clustering sub-armada hanya menguntungkan bila dataset cukup besar; cluster kecil -> overfitting.
- WTTE-RNN under-predict (konservatif), menguntungkan perencanaan pemeliharaan; galat dalam jendela aksi (~±25 timestep).
- Reduksi dimensi histogram via relative entropy efektif.

RELEVANSI KE TESIS
Inti-Metode: preseden industri WTTE-RNN yang mengombinasikan survival Weibull + RNN + data tersensor untuk keputusan pemeliharaan berbasis risiko, dan membahas trade-off censoring/small-data - sangat relevan bagi tesis. Domain bukan membran.
