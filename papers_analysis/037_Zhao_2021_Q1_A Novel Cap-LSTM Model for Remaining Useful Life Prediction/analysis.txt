Judul   : A Novel Cap-LSTM Model for Remaining Useful Life Prediction
Jurnal  : IEEE Sensors Journal | Scopus Q1 (SCImago SJR Best Quartile) | DOI 10.1109/JSEN.2021.3109623
Pilar   : B. Deep Learning RUL
Relevansi: Pendukung

KARAKTERISTIK STUDI
Studi pengembangan model prediksi RUL berbasis deep learning untuk turbofan engine, diposisikan dalam PHM untuk mengurangi biaya perawatan dan meningkatkan keandalan. Kontribusi utama adalah model hybrid dua kanal Cap-LSTM (capsule network + LSTM) yang mengatasi keterbatasan CNN konvensional.

METODE
- Dua kanal: (1) kanal capsule (conv 32 filter 3x3 ReLU -> 4 primary capsule -> 10 digit capsule 8-dimensi, dynamic routing 2 iterasi, squash) untuk fitur spasial; (2) kanal LSTM 100 neuron untuk dependensi temporal. Output digabung (concatenate) -> fully-connected 100 -> dropout 0,2 -> regresi RUL.
- Label RUL piece-wise linear (Eq. 15; knee point c_max-125), sliding time window (TW 30/21/36/18), z-score, MSE loss, Adam (lr 0,001), L2 0,0001, early stopping 20 epoch, maks 1000 epoch.

DATA
NASA C-MAPSS FD001-FD004, 21 sensor (14 dipakai). Train/test trajectory 100/100, 260/259, 100/100, 249/248. Split train 90% / valid 10%.

TEMUAN UTAMA
- RMSE Cap-LSTM 12,27/17,79/12,55/22,05 (FD001-FD004), terbaik vs 8 model (MLP, SVR, RVR, CNN, MODBNE, LSTM, BiLSTM, CNN+FNN).
- Score terendah (2,60e2 ... 4,57e3).
- Ablation: lebih baik dari Capsule saja dan LSTM saja.
- Window lebih panjang lebih baik dalam batas tertentu; dropout 0,2 optimal; Adam terbaik.

RELEVANSI KE TESIS
Pendukung: pembanding metode RUL deep learning yang tervalidasi pada benchmark publik dengan evaluasi berlapis. Namun tidak ada survival/penyensoran (SUMBU METODE gagal) dan bukan domain membran (SUMBU DOMAIN gagal). Berguna untuk rujukan arsitektur hybrid dan protokol evaluasi (RMSE + Score).
