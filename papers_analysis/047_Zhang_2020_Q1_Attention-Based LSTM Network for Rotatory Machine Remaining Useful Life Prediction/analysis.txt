PAPER 58 — Zhang et al. (2020)
Judul: Attention-Based LSTM Network for Rotatory Machine Remaining Useful Life Prediction
Jurnal: IEEE Access | Q1 (SCImago SJR Best Quartile) | DOI 10.1109/ACCESS.2020.3010066
Pilar: B. Deep Learning RUL | Relevansi: Pendukung | Skor kualitas: 9/10

KARAKTERISTIK STUDI
Studi RUL prediction untuk komponen rotasi (bearing) berbasis deep learning. Kritik terhadap model machine learning tradisional yang lemah pada sinyal non-linear kompleks. Menggabungkan ekstraksi fitur lokal (CNN) dengan pemodelan temporal berlapis (stacked LSTM) dan attention untuk menyorot informasi penting.

METODE
- TLSTM-A = 1-D CNN + dua lapis LSTM + attention mechanism + fully connected.
- CNN: 16 kernel, ukuran 64, aktivasi ReLU, max-pooling step 2 (ekstraksi fitur lokal dari sinyal getaran 1-D).
- Stacked LSTM: dua lapisan, 128 neuron per lapisan; output hidden diteruskan ke sel tetangga dan ke lapisan berikutnya.
- Attention: skor s = h_t * h_s, bobot alfa_ij = softmax; context vector c_i = sum alfa_ij h_j; bobot jaringan dimodulasi oleh beta.
- Pelatihan: loss RMSE, optimizer Adam, lr awal 0,005, normalisasi min-max RUL.
- Diskusi arsitektur: panjang input 1000, lr 0,005, 128 neuron LSTM-Attention dipilih.

DATA
Dataset bearing XJTU-SY (Xi'an Jiaotong University & Changxing Sumyoung Technology): 3 kondisi operasi, 15 bearing, run-to-failure. Diuji pada Bearing1_1, Bearing1_5, Bearing2_4. Fokus prediksi pada tahap failure (amplitude naik signifikan).

TEMUAN UTAMA
- TLSTM-A mengungguli CNN, CNN_SVR, CNN_MLP, RNN, OLSTM, TLSTM, OLSTM-A pada RMSE, MAE, dan Score.
- RMSE TLSTM-A: 102,36 / 258,19 / 183,74; MAE: 75,54 / 157,82 / 120,71; Score: 0,895 / 0,752 / 0,784.
- Dua lapis LSTM > satu lapis; attention meningkatkan akurasi.
- Panjang input >1000 tidak lagi menurunkan RMSE; lr 0,005 terbaik.

RELEVANSI KE TESIS
Baseline arsitektur deep learning RUL point-estimate dari sinyal sensor. Tidak menyentuh censoring maupun uncertainty quantification, sehingga memperjelas celah yang hendak diisi tesis (RUL membran dengan data tersensor + survival). Posisi: Pendukung.
