PAPER 047 - Cheng et al. (2020)
Judul   : Remaining Useful Life Prognosis Based on Ensemble Long Short-Term Memory Neural Network
Jurnal  : IEEE Transactions on Instrumentation and Measurement | Scopus Q1 (SCImago SJR Best Quartile) | DOI 10.1109/TIM.2020.3031113
Pilar   : B. Deep Learning RUL
Relevansi: Pendukung

KARAKTERISTIK STUDI
Studi pengembangan metode prognosis RUL untuk peralatan industri (turbofan engine) guna meningkatkan reliability, availability, dan maintenance cost. Mengusulkan ELSTMNN: ensemble LSTM yang digabung dengan Bayesian Inference Algorithm (BIA) untuk inferensi RUL optimal.

METODE
- Preprocessing: exponential smoothing (alpha=0,25) untuk menghilangkan singular point dan menekan fluktuasi; seleksi sensor via monotonicity (z), correlation (r), dan composite index SC=0,5|z+r| (ambang 0,75).
- ELSTMNN: M LSTMNN dilatih paralel, masing-masing pada dataset satu unit peralatan. BIA: estimasi prior N(mu_pi, sigma_pi^2) via maximum likelihood (Eq. 9-11), lalu posterior N(mu^BIA, V^BIA) (Morris empirical Bayes, Eq. 12-19). RUL optimal = modus distribusi.
- Hyperparameter: 80 LSTMNN, 25 sel hidden, dropout 0,2, 1000 epoch, batch 10, loss MSE, optimizer SGD.

DATA
NASA C-MAPSS FD001 dan FD003 (kondisi operasi tunggal), 100 engine latih + 100 engine uji, 21 sensor. 10 run berulang.

TEMUAN UTAMA
- FD001: MScore 5,71 (dev 0,19), RMSE 18,22 (dev 1,38), terbaik vs ANN, RVR, SVR, DCNN, ELM, DSE, RKRLS, SVM, EESN, EKF, ESKF, DLSTMNN.
- Validasi normalitas prediksi: Q-Q plot + uji Lilliefors (p>0,05).
- BIA mengalahkan bagging secara signifikan (uji ANOVA p=0,0029).
- Performa meningkat dengan M yang lebih besar.
- FD003: MScore 8,39, RMSE 23,21, mengungguli EBPNN/EMBPNN/EVRNN/EGRUNN.

RELEVANSI KE TESIS
Pendukung: contoh ensemble LSTM + inferensi Bayesian yang memfit distribusi prediksi untuk mengkuantifikasi ketidakpastian (d5), berguna bagi tesis dalam aspek ketidakpastian RUL. Namun tidak memodelkan penyensoran/survival (SUMBU METODE gagal) dan bukan domain membran (SUMBU DOMAIN gagal).
