PAPER 002 - Mi et al. (2014)
Judul   : Thermal Cycling Life Prediction of Sn-3.0Ag-0.5Cu Solder Joint Using Type-I Censored Data
Jurnal  : The Scientific World Journal | Scopus Q2 | DOI 10.1155/2014/807693
Pilar   : A. Survival Analysis & Censored Data
Relevansi: Inti-Metode (data tersensor + Weibull; tanpa ML, domain elektronik)

KARAKTERISTIK STUDI
Prediksi umur lelah sambungan solder bebas timbal SAC305 (BGA & FBGA) dari uji thermal cycling dipercepat. Fokus pada pemrosesan data tersensor interval Tipe-I dengan distribusi Weibull dan perbandingan terhadap model kelelahan Engelmaier serta Minitab/Matlab. Konteks: keandalan mikroelektronik.

METODE
- Uji ATC JEDEC JESD22-A104C (-40C..125C, 1 jam/siklus) pada PCB BGA (34x34, 1155 bola) dan FBGA (8x17, 136 bola).
- Kriteria gagal: area dyed >=30% atau >=10% sambungan gagal -> delta=1.
- Data tersensor interval Tipe-I (Eq. 4); likelihood tersensor (Eq. 6-7); MLE Weibull dua-parameter via metode dikotomi (Eq. 9).
- Model kelelahan Engelmaier yang dimodifikasi (Eq. 2-3, 12-13); faktor akelerasi Pan (Eq. 11).
- Pembanding: Minitab (MLE) dan Matlab (Powell's Dogleg).

DATA
Pengamatan pada siklus 0,250,500,750,1000,1500,2000,2500; 2 sampel tiap titik. Dua struktur SAC305 (BGA & FBGA).

TEMUAN UTAMA
- MLE Weibull data tersensor memberi eta=3104,5 / m=1,1 (BGA) dan eta=3185 / m=1,44 (FBGA).
- Nf metode Tipe-I > Engelmaier (BGA 3104,5 vs 2146,2; FBGA 3185 vs 2375), mendekati Minitab/Matlab.
- Kegagalan lelah = creep fracture, inisiasi retak di tepi luar solder / antarmuka solder-Cu.
- Faktor akelerasi Pan ≈ 35,5.

RELEVANSI KE TESIS
Contoh langsung formulasi likelihood untuk data tersensor dan estimasi Weibull, inti pilar A. Namun tidak ada machine learning, tidak ada RUL probabilistik, dan domain elektronik (bukan membran/RO). Berguna sebagai acuan cara menangani censoring Tipe-I.

- d3=1: inti studi - data tersensor interval Tipe-I (delta_i, Eq. 4) + likelihood Weibull (Eq. 6-9).
- d4=1: model spesifik - Weibull dua-parameter (MLE) + model kelelahan Engelmaier dimodifikasi.
- d5=1: interval kepercayaan 95% (plot kegagalan kumulatif, prediction bounds Matlab, CI parameter m 1,087-2,229).

- d7="": objek solder elektronik, bukan membran/RO.
- d8="": bukan small-data/transfer/hierarchical; sebagian kegagalan teramati, bukan all-censored.
