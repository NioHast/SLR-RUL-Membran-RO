PAPER 79 — Ramadhan et al. (2026)
Judul: Machine Learning for Covariate-Driven Changes in Weibull Scale Parameter
Jurnal: Engineering, Technology & Applied Science Research (ETASR) | Q3 (SCImago SJR 2024) | DOI 10.48084/etasr.15186
Pilar: A. Survival Analysis & Censored Data | Relevansi: Inti-Metode | Skor kualitas: 8/10

KARAKTERISTIK STUDI
Studi yang mengkritik model survival statis konvensional untuk estimasi RUL. Premis: characteristic life (parameter skala Weibull, lambda) bukan statis melainkan fungsi dinamis dari kovariat operasional/lingkungan. Model AFT klasik mengasumsikan hubungan linear yang terlalu kaku; paper memakai machine learning terawasi untuk menangkap hubungan non-linear kovariat-lambda, sekaligus menempelkan prediksi ke kerangka probabilistik Weibull.

METODE
- Dasar: distribusi Weibull dua-parameter (PDF/CDF); RUL sebagai variabel acak; waktu kegagalan direkonstruksi (siklus terakhir + RUL ground truth).
- Estimasi awal parameter via MLE (k diselesaikan iteratif; lambda dari rumus).
- Baseline: AFT-OLS, lambda(X) = lambda_base * e^-(beta^T X).
- ML: Linear Regression, SVR, Random Forest (bagging), XGBoost, LightGBM (boosting).
- Target transformasi: y = lambda(1 - t/t_RUL) (degradasi linear dari characteristic life ke nol saat gagal).
- Preprocessing: SMA denoising (window w), StandardScaler.
- Hyperparameter: grid search.
- Metrik standar (MAE/MSE/RMSE) + metrik Weibull-kustom baru: MWE, MLWE, MRWE, MQWE (area antara CDF Weibull dan step function kegagalan).

DATA
NASA C-MAPSS FD001: 100 lintasan latih + 100 lintasan uji; 21 sensor + 3 setelan operasi; satu kondisi operasi. Parameter Weibull terestimasi: k=4,359886822599401; lambda=236,7659325811420 (k>1 → wear-out).

TEMUAN UTAMA
- Semua model berbasis kovariat mengalahkan baseline statis NC → characteristic life memang bergantung kovariat.
- LightGBM terbaik: MAE 25,44; MSE 1170,52; RMSE 34,21; MWE 27,16; MLWE 9,07; MRWE 18,09; MQWE 1058,44.
- XGBoost (26,59) dan RF (26,62) menyusul; LR (35,43) dan SVR (29,74) di tengah; AFT-OLS (36,17) hampir setara NC (38,50).
- Metrik Weibull-kustom berkorelasi dengan metrik regresi standar → validasi metrik baru.
- Ensemble boosting mengungguli model klasik karena menangkap dinamika degradasi non-linear.

RELEVANSI KE TESIS
Inti pada sumbu metode: analisis survival Weibull + RUL + pemodelan lambda sebagai fungsi kovariat (sangat relevan karena tesis juga memodelkan RUL membran terhadap kovariat operasional) dan penempatan prediksi ML dalam kerangka probabilistik. Namun tidak menangani data tersensor secara eksplisit dan domainnya turbofan. Posisi: Inti-Metode.
