PAPER 61: Harnessing machine learning for transmembrane pressure prediction in MBR systems during textile wastewater treatment
Penulis: Onaira Zahoor, Sher Jamal Khan, Muhammad Usama, Henry J. Tanudjaja, Noreddine Ghaffour, Muhammad Saqib Nawaz (2025)
Jurnal: Desalination and Water Treatment | Scopus Q3 | DOI 10.1016/j.dwt.2025.101238 | Pilar: E. Membrane/RO/Desalination

KARAKTERISTIK STUDI
Studi aplikatif domain membran: memprediksi transmembrane pressure (TMP) pada Membrane Bioreactor (MBR) skala bench yang mengolah air limbah tekstil sintetik. TMP dipakai sebagai proksi langsung proses fouling membran. Fokusnya bukan RUL, melainkan pemodelan regresi ML + interpretasi parameter lumpur.

METODE
Tiga model regresi: Random Forest (RFR), Support Vector Regression (SVR), dan Lasso (L1R). Seleksi variabel memakai effect size >=0,3 dan signifikansi <0,001 -> lima predictor: B_Car, MLSS, SOUR, DSVI, PSD. Split data kronologis 80/20 (46 train / 12 test) untuk menghormati autokorelasi. Grid search untuk hyperparameter (ntree=500, mtry=2, cost=1, gamma=0,1, lambda via CV). Analisis partial dependence (PDP) untuk interpretasi mekanistik dan deteksi bias nilai ekstrem.

DATA
MBR acrylic 16 L, membran hollow fiber PVDF 0,1 mikron (0,2 m2), HRT 12 jam, SRT 30 hari, aerasi kontinu. Data 60 hari (tiga siklus membran 19-21 hari), 58 observasi harian, 60 dataset (5 input + 1 output) = 360 titik data. Membran fouling pada ambang TMP 30 kPa.

TEMUAN UTAMA
- RFR terbaik: R2 0,95 (train) / 0,83-0,86 (test); RMSE 1,75 kPa / 3,3 kPa. SVR: R2 0,87/0,74. L1R: R2 0,81/0,69.
- B_Car (bound EPS karbohidrat) paling penting (korelasi 0,83; kenaikan MSE ~60%), lalu DSVI (0,76), MLSS (0,58), SOUR (0,62), PSD terlemah.
- Ambang DSVI ~68-70 mL/g memicu kenaikan TMP tajam; TMP naik dengan B_Car 24-32 mg/L.
- RF/Lasso lebih akurat pada nilai ekstrem; SVR cenderung konservatif.
- Interval prediksi 80% disediakan (bootstrap); grid search mengukur ketidakpastian hyperparameter.

RELEVANSI KE TESIS
Inti-Domain. Sangat relevan pada sumbu domain (membran/fouling, small-data, ketidakpastian prediksi), tetapi belum menyentuh sumbu metode inti tesis: tidak ada RUL, survival analysis, atau pemodelan data tersensor. Berguna sebagai bukti bahwa proksi degradasi (TMP) dapat dimodelkan ML dengan data kecil, dan sebagai pembanding bahwa literatur membran jarang memformalkan waktu-ke-gagal secara survival.
