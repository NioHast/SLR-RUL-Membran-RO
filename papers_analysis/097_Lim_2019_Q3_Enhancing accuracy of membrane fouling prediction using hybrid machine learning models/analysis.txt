PAPER 028 - Lim et al. (2019)
Judul   : Enhancing accuracy of membrane fouling prediction using hybrid machine learning models
Jurnal  : Desalination and Water Treatment | Scopus Q3 (SCImago SJR Best Quartile) | DOI 10.5004/dwt.2019.23444
Pilar   : E. Membrane/RO/Desalination
Relevansi: Inti-Domain

KARAKTERISTIK STUDI
Memprediksi resistansi membran (indikator fouling) pada proses SWRO dengan model machine learning hibrida (Kalman filter + ANN/SVM), memakai data pabrik Fujairah selama 18 bulan. Bertujuan menyesuaikan jadwal pembersihan/penggantian membran.

METODE
- Kalman filter menapis derau data operasional; hasilnya dipakai melatih ANN atau SVM (dirangkai seri) -> KF-ANN, KF-SVM.
- Resistansi membran dari teori transport: R_tot(t) = (dp - dpi)/v(t) (Eq. 3) dan model resistance-in-series (Eq. 1-2).
- ANN: 3 lapis (D input, M hidden, K output), MSE (Eq. 9-11). SVM: regresi dengan kernel (Eq. 12-15).
- Evaluasi NSE dan R2; peramalan 7 dan 14 hari.

DATA
522 catatan harian (Jan 2005-Jun 2006), 8 input (T, Qb, Qp, Pf, Pb, Pp, Cf, Cp), output resistansi membran. Temperatur 23-36 C; TDS umpan 34.920-39.538 mg/L; recovery ~43 %.

TEMUAN UTAMA
- Hybrid > single: NSE uji ANN 0,45 -> KF-ANN 0,63; SVM 0,46 -> KF-SVM 0,72.
- KF-SVM terbaik (R2 uji 0,82; NSE uji 0,72) dan stabil saat horizon peramalan digandakan.
- Model fouling klasik hanya memprediksi tren naik, bukan nilai aktual.
- Berguna untuk early warning dan penyesuaian jadwal pembersihan/penggantian.

RELEVANSI KE TESIS
Inti domain: prediksi degradasi membran (resistansi/fouling) SWRO + keputusan pemeliharaan (jadwal cleaning/replacement). Namun tidak ada RUL formal, survival, atau pencensoringan, sehingga menyumbang domain + maintenance, bukan metode survival. Diklasifikasikan Inti-Domain.
